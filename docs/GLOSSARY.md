# Glossary

**Board** — Physical microcontroller/edge board.

**Device** — Configured physical controller installed for a machine.

**Machine** — Maintainable industrial asset tracked by Maintain.ai.

**Sensor** — Physical instrumentation attached to a device.

**Parameter** — Measurable output produced by a sensor.

**Configuration** — Versioned board + machine + sensors + pins + communication settings.

**Firmware build** — Generated and compiled firmware artifact.

**Telemetry** — Time-stamped measurement data emitted by a device.

**Registry** — Versioned machine-readable board/sensor definition.

**Adapter** — Integration layer translating DeviceOS data to an external target.

**DeviceOS** — Maintain.ai's local device provisioning and edge configuration product.
